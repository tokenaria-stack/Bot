strings from the mount-time renderOptions copy (not a snapshot written
into localStorage).

C. STORE
--------

Key: wozduh_color_prefs_v1

Shape (sparse, canonical IDs only):

    {
      "woz_vol_rsi_ema12": { "color": "#C58EAC" },
      "woz_rsi_close_chan": {
        "upperColor": "#55739A",
        "midColor": "#800000",
        "lowerColor": "#55739A",
        "fillColor": "#8A7058"
      }
    }

Storage format: #RRGGBB (normalized uppercase).
Named CSS / rgba / #RGB rejected.
Unknown IDs and unknown fields ignored on apply.
Empty map → removeItem (no copied defaults).


D. COMMAND API (DDRFactory)
---------------------------

setWozduhColor(id, field, hex)
resetWozduhColor(id, field)
resetWozduhComponentColors(id)
resetAllWozduhColors()
applyWozduhColorOverrides()

hostId must be wozduh. kind line | channel.
Does not call setSeriesVisible or onSubscriptionChange.


E. FILL
-------

Store fillColor as #RRGGBB.
Apply as rgba(r,g,b, alpha) where alpha is parsed from the factory
manifest fillColor string. No hardcoded 0.12 in the override module.
Unparseable factory fill → skip fill paint (fail closed).
Reset fill restores the factory rgba string.
