3. THREE CLOCKS
============================================================

Evaluate clock
    Field + comparator + bound
        → Evaluate
        → state.last.pass (authoritative membership)
        → header — / pass.length
        → Prev / Next walk
        → paint Lens form (histograms, sliders)

Viewport clock
    visible unix range
        → viewCount  (Chart view number)
        → marksInView → getMarks
        → populationPlan of that slice
        → requestUpdate

Draw clock
    primitive.glyphs already clipped
        → candle high/low at each mark (binary search)
        → path at that Y

Pan no longer rebuilds histogram SVG. That was a second lag
source GPT's overlay note underweighted.

============================================================
4. GATEWAY
============================================================

getMarks() is the only chart paint list.

    showStars off → []
    else marksInView(pass, viewFrom, viewTo)

marksInView does not copy rows and does not filter pass.
Prev / Next still receive the full pass order from Evaluate.

bin.count is never a paint list.

============================================================
5. CANDLE LOOKUP
============================================================

ChartAdapter.candleHighLowAt scanned the columnar store from the
tip for every glyph. After clipping, a zoomed-out 15m window can
still contain hundreds of marks; each O(n) scan was the dominant
cost.

The store times are ordered. The lookup is now a binary search.
Semantics are unchanged: exact unix-second match, high/low of
that candle.

Not LOD. Not a downsample. Missing candles still skip the glyph.
