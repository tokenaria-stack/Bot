============================================================
5. OK FLAGS
============================================================

A relation is value and OK.
Both operands must be observations.
Otherwise the stored value is 0 and OK is false.
A result of 0 with OK true is a real tie.

VWEMA and orange mid have no OK flag on the
snapshot. ValuesOK also requires the channel
bounds, so it is not their gate. The gate is
Present and a finite number. An absent bar
stores 0, and Present false keeps that 0 from
being read as a VWEMA of zero.

Every other line uses its own OK flag, and
Present must be true. Width uses WidthOK.
Close width uses CloseWidthOK.
