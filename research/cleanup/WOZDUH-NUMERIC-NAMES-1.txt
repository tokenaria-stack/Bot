-------------------------

1. Color-named compute bits were also renamed (not only Wt11/Wt22). Leaving
   WozduhBitOrangeBase as a live math identity would fail the chapter's own
   "no color in mathematical identity" success condition. Bit values/order
   unchanged.

2. MACD period identifiers wozduhMacdFast / wozduhMacdSlow were kept. They
   are standard MACD 7/24 names, not the retired Wozduh plot pair.

3. SlotOrangeRSI is a reserved Chaos slot, not Wozduh RSI-close. Untouched.

4. Internal volVwap → volVwema names the existing VolumeWeightedEMA. No new
   published VWEMA/RSI24(VWEMA) slots (GPT correctly forbade those).

5. Prefs: delete retired woz_* keys after copy so localStorage does not keep
   a dual vocabulary. Falcon rsiVol remains as the existing source key.

6. migrateLegacyPrefs is exported only so the existing node-test style can
   lock the remap. Not a migration framework.

7. Unused ChartTheme wozduhFast/wozduhSlow keys renamed; values still
   'blue'/'aqua'. Layout paint is still the SSOT for line colors.

8. Navigator return name wozSlow → wozVolRsiEma5 (same SlotWozduhVolRsiEma5
   series). Callers already used a generic woz variable.
