3. CORRECTION TO THE PROMPT
============================================================

CountBins remains the original right-closed counter
(v <= edge, plus overflow). That contract cannot express
[from, to) without an epsilon hack.

Display histograms therefore count with CountHalfOpen:

    v < cut0            → first bin  (open below)
    cut[i] <= v < cut[i+1]
    v >= last cut       → last bin   (open above)

CountHalfOpen is the same counting family, presentation-only.
It is not a second observation set and not a new evaluator.
NumberPicture.Values remain the only observations.

DisplayBinCount: n<80 → n bins, else 64. Not a research constant.

============================================================
4. DATA FLOW
============================================================

    NumberPicture (self-exclusion unchanged)
        ↓
    DisplayHistogram → CountHalfOpen
        ↓
    HTTP hist[{from,to,count,openLow?,openHigh?}] + observed + missing
        ↓
    browser draws those bins
        ↓
    click uses the bin's from/to
        ↓
    KindContinuous (no KindRange)
        ↓
    Evaluate → state.last.pass

Interior: Field >= from AND Field < to
First (openLow): Field < to
Last (openHigh): Field >= from
Degenerate min==max: Field >= from
