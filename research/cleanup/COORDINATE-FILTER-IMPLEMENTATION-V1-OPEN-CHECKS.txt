============================================================
4. JOIN ASSUMES INDEX ALIGNMENT
============================================================

AttachCoordinates requires:

    len(rows) == len(snaps) == len(rels)
    snaps[i].ConfirmedAt == rows[i].DecisionAt
    snaps[i].Side == rows[i].Side
    same for Matrix ConfirmedAt/Side

It does not match by scanning decisionAt if order diverges.
Frozen artifacts are the same 8783 order. A future file that
is sorted differently will fail at i, not rematch.

ConfirmedAt is used as the Schema 3 / Matrix clock. Outcome
uses DecisionAt. Frozen equality is certified; if a later
artifact splits those clocks, join breaks.

CHECK LATER:

    If a mismatch appears, fail loud (already does per index).
    Do not fuzzy-match by time ignoring index.
