3. LAYOUT
============================================================

#tool-dock
    position:absolute; right:0; width: 40px; z-index 40
    always in #workspace-main

#star-inspection
    right: var(--tool-dock-width)
    hidden when closed (display:none via [hidden], node kept)

#tab-live padding-right
    calc(--tool-dock-width + --star-inspection-width)

When the panel is an overlay (narrow window), --star-inspection-width
is 0 so the chart only loses the dock. The floating panel still sits
left of the dock, not on top of it.

Existing drag-resize of the research pane still calls applyWidth.

Chart size still comes from ChartAdapter ResizeObserver on the host.
No second sizing path.
